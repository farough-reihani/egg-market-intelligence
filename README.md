# هوش بازار تخم‌مرغ

سامانه آزمایشی تحلیل بازار تخم‌مرغ با رابط فارسی و راست‌چین.

## ساختار صفحات
- `index.html`: صفحه اصلی عمومی و نمودار شاخص اختصاصی قیمت بازار
- `dashboard.html`: داشبورد مدیریتی آزمایشی برای ثبت و بررسی خریدهای شخصی
- `market.html`: مسیر جایگزین برای مشاهده نمودار شاخص

## وضعیت فعلی
- نمودار شاخص از جدول `market_index_points` در Supabase داده می‌خواند.
- هنوز نقطه شاخص واقعی وارد نشده است؛ تا زمان تعریف و محاسبه شاخص بر پایه داده‌های معتبر، نمودار خالی می‌ماند.
- خریدهای ثبت‌شده در داشبورد فعلاً فقط در `localStorage` همان مرورگر ذخیره می‌شوند و به پایگاه داده یا صفحه عمومی منتقل نمی‌شوند.
- جمع‌آوری خودکار پیام‌های تلگرام و پردازش داده‌های منابع هنوز پیاده‌سازی نشده است.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای مدیریت خریدها، وارد `dashboard.html` شوید.
