# هوش بازار تخم‌مرغ
نسخه آزمایشی رابط کاربری فارسی و راست‌چین.

## امکانات فعلی
- ثبت خرید با چهار فیلد: برند، وزن متوسط هر کارتن، نوع تخم‌مرغ (زرده معمولی/زرده طلایی)، قیمت خرید
- تاریخچه خرید و خروجی CSV
- افزودن و حذف برندها و منابع قیمت
- داشبورد خلاصه

## اجرا
فایل index.html را در مرورگر باز کنید.

## محدودیت مهم
این نسخه نمونه اولیه است. داده‌ها فقط در localStorage همان مرورگر ذخیره می‌شوند؛ پایگاه داده آنلاین، ورود امن، همگام‌سازی بین دستگاه‌ها و پشتیبان‌گیری سروری هنوز پیاده‌سازی نشده‌اند. اطلاعات محرمانه یا واقعی وارد نکنید تا زیرساخت امن اضافه شود.
